Tracker settings

Admin-configurable SLA rules and dropdown lists — aligned to the TGS-MOA spreadsheet.

Business rules

Defaults match WRU Traffic TGS-MOA Tracker V6 (must-have −20 bus. days, priority on must-have ≤14d, council assume +10 bus. days, MoA wait SLA 20).

Roads

This is the road list used on Add site, the register, Client lists, and Permits/TRIMS exports. Rename a road here to correct it everywhere it is used. Remove hides it from the dropdown; it does not delete sites.

    Councils

    Rename a council to update every site that uses it. Remove hides it from council dropdowns.

      Import spreadsheet

      Upload the WRU Traffic TGS-MOA Tracker as .xlsx or .xlsm (legacy .xls must be saved as .xlsx first). Off-site, Zscaler / Cloudflare often block a spreadsheet upload; Preview and Import send JSON pieces instead of the workbook file. Update first, then retry. Rows match on road + site number.
