Backup & migrate

Take a full copy of this server — database, uploaded files, and config — and restore it on a new machine.

Export

Downloads a .zip with a PostgreSQL dump, every file in Documents / map / cost attachments, and config such as the Nearmap key. Users, stages, rates, and sites are all inside the dump. Keep this file off the tracker server.

Import onto this server

This replaces the live database and uploaded files with the backup. Use it to move WRU to a new server after a fresh install. Import sends JSON chunks so workplace filters do not block the zip. Everyone should be logged out of ops while this runs.
