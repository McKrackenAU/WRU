File storage

Pick a disk or mount the server can see (for example /mnt). WRU creates the rest of the path on save. Changing a location does not move existing files — copy them first when you cut over to a larger disk.

Use one disk for everything

Choose a mount, then apply it to documents, cost estimates, KML, and backups. Example: /mnt becomes /mnt/uploads, /mnt/uploads/kml, and /mnt/backups.
